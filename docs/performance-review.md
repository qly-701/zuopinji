# 性能审查与优化记录

日期：2026-11-14。基线为上一已发布版本 `09e261a1cab2b2a93cb255e251f05fe7d55298d5`，使用相同依赖重新构建对比。文件字节数见 `performance-metrics.json`。

## 发现与处理

| 范围 | 发现 | 已实施 |
| --- | --- | --- |
| 视频与图片 | 首页轮播直接使用详情尺寸图片；背景视频为1080p/30fps | 图片按显示尺寸提供WebP与srcSet；详情采用高质量版本，软件放大仍使用原图。循环视频采用720p/24fps、无音轨、faststart，保留原慢推近轨迹 |
| WebGL | lazy组件在首屏JSX中即被渲染，因此提前加载Three.js并创建上下文；DPR上限1.5且按屏幕帧率绘制 | opening完成后、内容接近视口才加载；默认30FPS/DPR1；离屏、后台、弹窗时取消RAF；动态减弱设置静态单帧；复用renderer，改用ResizeObserver缓存尺寸，并精简等价Shader计算 |
| 滚动监听 | 轮播悬停、焦点和手动保护期间仍每帧空转；每个wheel事件直接写scrollLeft | 暂停时取消RAF；仅一个恢复计时器；高频滚轮累加到下一帧，一帧一次写入。保留双向循环、Ctrl缩放放行及键盘控制。导航仍由IntersectionObserver更新，没有新增全页scroll监听 |
| GSAP | 多个组件同帧分别调用全局refresh；开场给所有重复轮播卡执行动画 | 合并refresh请求并支持独立取消；只对可见轮播执行进场；保留上下文清理、局部筛选重建、桌面视差与减弱动画策略 |
| 首屏 | 加载页等待所有封面、字体和视频loadeddata，最多9s后再退出；CountUp另引入motion库 | 只等关键海报，字体和视频不作为可用性门槛；最多1500ms开始退出，退出650ms；数字进度改用已有GSAP，保留原样式。视频放行后才挂URL，省流量/2G/减弱动画默认海报。字体改WOFF2并将字体CSS提前发现 |
| React与清理 | 根导航/复制状态可重渲染24张轮播与14张软件卡；复制反馈可积累计时器 | memo静态子树；复制反馈重用一个计时器；离屏暂停装饰轨道CSS动画 |

## 静态文件结果

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 六封面缩略图，去重URL合计 | 803,585 B | 95,670 B（480px），190,518 B（800px） |
| 循环视频 | 2,261,672 B | 583,775 B |
| 海报+六缩略图+完整视频文件组合 | 3,162,943 B | 746,989 B（480px缩略图组合） |
| 主脚本 gzip | 170,664 B | 144,496 B |
| 八个字体文件合计 | 730,904 B TTF | 247,544 B WOFF2 |
| 详情专用大图合计 | 5,627,572 B | 3,072,926 B |

这些是文件预算，不是浏览器实际传输测量。srcSet会随视口和DPR选择不同图片；24个轮播img复用6个URL，不等于24次网络下载。字体由浏览器按使用字重加载；WebGL模块现在延后加载。PDF、源图和未引用的历史素材不计入首屏预算。原始文件保留供PDF和原稿使用，因此静态发布目录总大小并不等于首屏请求量。

1500+650ms是加载遮罩的上限策略，不是完整首屏加载时间；原有opening节奏继续保留。

## 验证

- 生产构建、git diff检查通过。
- 图片衍生文件逐一解码、尺寸及无放大检查通过；软件放大原文件保留；视频帧对比、24FPS、无音轨和faststart核验通过。
- 八份WOFF2字符映射与原TTF一致。
- 现有功能回归通过：项目详情、轮播/滚轮、筛选、软件原图放大、联系方式及已移除的下载入口。
- 实际GSAP在DOM模拟中通过开场完成、筛选反复切换、视差断点、减弱动画与卸载清理验证。
- 控制时钟/RAF/IO测试通过资源卡住兜底、hover/focus/后台/离屏停帧、100个wheel事件一帧一次写入、单计时器恢复、refresh合并/取消、视频节流策略及背景延迟加载。
- ColorBends生命周期使用Mock WebGLRenderer验证停帧、FPS/DPR、单帧、resize缓存、上下文丢失及释放。

当前环境没有可调用的浏览器控制工具。未取得真实设备的LCP、INP、FPS或GPU功耗数据；DOM/Mock测试不代表像素或GPU基准，未据此给出Lighthouse跑分。
